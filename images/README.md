# 商品圖片說明

此目錄用於存儲 Viebucks Coffee 商品圖片。

## 圖片上傳指南

### 支持的格式
- JPG / JPEG
- PNG
- WebP

### 命名規則
圖片應按商品 ID 命名：
- `p1.jpg` - Arabica 100% (250g)
- `p2.jpg` - Arabica 100% (500g)
- `p6.jpg` - Robusta 100% (250g)
- 等等

### 圖片大小建議
- 推薦寬度：800px
- 推薦高度：600px
- 文件大小：< 500KB

### 使用方式

在 sales 系統中，圖片會自動從此目錄加載：
```
https://raw.githubusercontent.com/rick0960590177/viebucks-coffee/main/images/[product-id].jpg
```

例如：
```
https://raw.githubusercontent.com/rick0960590177/viebucks-coffee/main/images/p1.jpg
```

### 如何上傳圖片

1. 進入此文件夾：https://github.com/rick0960590177/viebucks-coffee/tree/main/images
2. 點擊「Add file」→「Upload files」
3. 選擇要上傳的圖片
4. 確認上傳

圖片上傳後會自動在 sales 系統中顯示！
